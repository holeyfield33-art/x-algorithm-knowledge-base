# Creator Growth Playbooks

Practical, algorithm-aligned playbooks derived from the open-source For You ranking system.

## Available Playbooks

| File | Audience | Description |
|------|----------|-------------|
| `ai-security-small-account.md` | @1Aihub and similar (AI security, low follower count) | Specific daily/weekly system for growing an AI security account from ~15 followers |
| `brand-new-account.md` | Anyone starting from 0 followers | 45-day ramp for a completely new page |
| `general-principles.md` | All creators | Core rules that apply regardless of niche |

## How These Were Built
- Based on public weights and logic in `xai-org/x-algorithm`
- Prioritize high-weight actions (replies, quotes, copy-link, shares, follows)
- Explicitly avoid patterns that trigger strong negative predictions or visibility drops
- Account for author diversity decay and freshness filters

## Usage
1. Choose the playbook that matches your current stage.
2. Follow the daily and weekly systems consistently.
3. Track replies, quotes, and shares more than pure likes or impressions.
